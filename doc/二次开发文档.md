## 1. 项目概览

参考人脸识别消费机（`E:\WorkBuddy\ConsumerMachineProject`）的旷视算法内核与接口协议，开发的独立 Android APP：

- **核心流程**：心跳触发 → GET 拉取待同步照片 → 4 线程下载/解码/检测/旷视提特征（不落盘）→ POST 整批上报结果（status + 失败原因 + faceFeature + featureMD5）→ 写 SQLite 历史。

## 3. 工程结构与核心文件

```
app/src/main/java/com/hpt/faceextraction/
├── App.java              # 初始化旷视 FaceCore（setFaceConfig → sdkInit → certification）
├── MainActivity.java     # 界面：标题栏/任务状态/资源状态/历史列表/设置弹窗（含 HISTORY_LIMIT=50）
├── FaceSyncTask.java     # 同步调度：GET 拉取、parseResponse 多格式解析、TaskIdentifier、
│                         # 4线程 runTask、uploadResults（clientID/TaskIdentifier/algoVersion/featureMD5）
├── TimeSyncTask.java     # 心跳：Status=100 判在线、校时、解析 UploadImage 触发 syncIfIdle()
├── FaceExtractor.java    # 单张：下载→解码(≤1000px)→detectFaces 多人脸/分数阈值→detectBitmap 提特征
├── HttpUtil.java         # OkHttp 全局拦截器：Client-ID / sn / mac 协议头
├── Config.java           # SharedPreferences：httpHost/deviceNumber/httpInterval/syncSize/faceScore/webPassword
├── WebConfigServer.java  # 内置配置服务（8090，ServerSocket 实现），含万能密码 MASTER_PASSWORD
├── TaskHistoryDb.java    # SQLite v3：task_time/photo/success/fail/duration_ms/task_id
├── NetMonitor.java       # 以太网/WiFi 状态、IP
├── Constants.java        # SN 读取、getMac()/getActiveMac()/getEthernetMac()/getWifiMac()
└── BootReceiver.java     # 开机自启（BOOT_COMPLETED）
```

**算法资产（缺一不可）**：`app/libs/pipeline-orig.jar`、`app/src/main/jniLibs/armeabi-v7a/*.so`、`app/src/main/assets/models/*.bin`（8 个旷视模型）。

## 4. 关键技术点与坑（务必先读）

1. **pipeline-orig.jar 资源 ID 冲突**：jar 内固化的 `com/hpt/facepass/R*` 已删除，由源码 `com/hpt/facepass/R.java` 提供正确 ID（0x7f0d003f~46）。
   ⚠️ **strings.xml 中 mcv_* 之前的资源不可随意增删**，否则 ID 错位运行时崩溃；改动后用 `aapt2 dump resources` 校对。
2. **旷视 SDK 依赖**：RxJava3(3.1.8)+rxandroid+kotlin-stdlib(1.4.32) 必须在 build.gradle；缺 libacendpoint.so 会初始化失败。
3. **initHandle error 58** = fileRootPath 目录不存在：sdkInit 前必须 `mkdirs filesDir/facelib`（App.java 已处理）。
4. **MAC 读取**：Java `getHardwareAddress` 在该设备返回全 0，必须读 `/sys/class/net/{iface}/address`（eth0 优先）。
5. **心跳 Time 校验位**：15 位 = yyyyMMddHHmmss + 1 位校验位，取前 14 位按东八区解析；偏差 >10s 才校时。
6. **同步不轮询**：仅心跳响应 `UploadImage`(true/"1"/"是"，兼容别名) 触发；处理中收到触发自动跳过；`syncNow()` 仅界面按钮用。
7. **签名**：debug/release 都用 platformrk.jks（平台签名），否则 `sharedUserId="android.uid.system"` 安装即失败；签名路径用 `keystore/` 相对路径（中文绝对路径会乱码）。
8. **上报协议（v1.1）**：根层 `clientID / TaskIdentifier(有才带) / algoVersion / result / models[]`；成功项带 `faceFeature` + `featureMD5`（Base64 串的 MD5，32 位小写）。
