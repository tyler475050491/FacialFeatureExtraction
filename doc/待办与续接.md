## 二、待办 / 已知问题

1. **【重要】支持"特征码"下发模式**（来源：docs/消费服务端说明.txt）
   - 服务端约定两种模式：① 特征码优先——同步响应带 `faceFeature` + `algoVersion` 时设备直接用特征码，不下载照片；
     ② 人脸模式——带可访问的 `faceDataUrl`。
   - **当前 APP 只实现了人脸模式**（collectEntries 只认 faceDataUrl/url）。
     需求已明确要支持特征码模式，续接时在 `FaceSyncTask.parseResponse/collectEntries` 增加 faceFeature 分支处理。
2. **算法商城在线激活 error 10004**：芯片授权已通过、本地提取不受影响，持续观察即可。
3. **服务端循环下发**：曾出现同批 50 张反复下发（上报成功未对账）。APP 侧已支持 TaskIdentifier 对账回传，需服务端配合；若复现，从服务端排查。
4. **size 默认值迁移逻辑**：Config 有一次性迁移（旧默认 1000 → 200），新设备无需关心，仅提醒勿删该标记。

## 三、续接操作清单（换电脑）

1. 按 `doc/二次开发文档.md` 2.1~2.3 装好 JDK17/Gradle8.7/SDK，改 `local.properties`，跑一次 `assembleDebug` 验证环境。
2. 确认 `app/keystore/platformrk.jks` 在（平台签名，丢了这个无法装到设备）。
3. `adb connect <设备IP>:5555` 连真机；设备 IP 可能变化，连不上向使用方要新地址。
4. 改代码 → `assembleDebug` → `adb install -r app\build\outputs\apk\debug\app-debug.apk` → `am force-stop` + `am start` 重启验证。
5. 每日开发过程记入 `doc/会话记录/YYYY-MM-DD.md`，完成后更新本文件的"当前状态"。
